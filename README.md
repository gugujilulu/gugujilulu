## Selected Work

### Healthcare Risk Model Validation

**External validation, calibration, local model updating, robustness analysis, and temporal validation for mammography-based breast cancer risk prediction.**

- Provincial retrospective context with up to **438,571 screening exams** across **1–5 year cumulative risk horizons**
- Evaluation spanning **ROC AUC, Brier score, E/O ratio, calibration slope/intercept, decile calibration, subgroup analysis, and patient-cluster bootstrap**
- Prediction-level local updating with **regularized logistic regression and LightGBM**
- Future-period temporal validation, first-exam sensitivity analysis, leakage auditing, and decision-curve analysis
- Public-safe repository with curated aggregate evidence and a fully runnable synthetic reconstruction

**Stack:** Python · pandas · NumPy · scikit-learn · LightGBM · pytest · GitHub Actions
